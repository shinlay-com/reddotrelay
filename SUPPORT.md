# Support policy

Community support is best-effort and has no response-time or resolution-time
commitment. Use GitHub Discussions for usage questions and GitHub Issues for a
minimal reproducible Engine defect or approved feature proposal. Search existing
reports first and remove credentials, signed URLs, customer payloads, and other
sensitive information.

Only versions listed by the compatibility and release policies are supported.
Maintainers may close reports for modified binaries, unsupported deployment
shapes, or versions outside the support window after identifying the boundary.

Use the private process in `SECURITY.md` for vulnerabilities and the private
contact in `MAINTAINERS.md` for conduct incidents. Commercial support, managed
operations, SLAs, and RedDotRelay Cloud are separate offerings and are not
implied by this repository.
