# Maintainers

Maintainers own release decisions, compatibility governance, security response,
and repository moderation. The public repository owner must replace this
bootstrap section with named maintainers and a private conduct-reporting contact
before the first supported release.

Until those identities are published, changes require explicit repository-owner
approval. The GitHub Security tab is the private channel for vulnerabilities;
ordinary support belongs in public discussions as described in `SUPPORT.md`.

Maintainer changes require approval from the repository owner and must be made
in a reviewed pull request. No person may approve their own addition or removal.
